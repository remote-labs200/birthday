# A little birthday surprise

A small, responsive birthday page made with plain HTML, CSS, and JavaScript. It has no build step or paid services. Subtle falling glitter decorates the page without blocking clicks or adding page overflow. The optional birthday soundtrack uses the audio track in `assets/background-music-birthday.mp4`; the video stays hidden, and playback starts only when the visitor presses the music button. The birthday moodboard opens images in a full-screen viewer with animated balloons and sparkles; close it with the × button or Escape.

## Make it yours

1. Open `script.js`.
2. Update the `birthdayDetails` values: the recipient's name, your name, the three friendship notes, the rotating reminders, and the closing message.
3. Keep the wording personal and friendly; replace any lines that don't sound like you.
4. The `assets` folder contains decorative moodboard portraits. They are labeled as decorative and are not presented as photos of Chandrika. Replace them with photos she has shared if you want a personal gallery.
5. Open `index.html` in a browser to preview it. For local development, you can also use VS Code Live Server.
6. Publish the folder with a static host such as GitHub Pages, Netlify, or Vercel, then send her the link.

The page uses a Google Fonts stylesheet when a network connection is available and falls back to system fonts otherwise. Only add photos or other personal details that your friend would be comfortable having on a shared link.
